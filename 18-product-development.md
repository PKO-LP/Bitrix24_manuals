# Урок 18. От запроса к первой версии программы

**Большая практическая работа на два академических часа.** Битрикс24 используем для плана и результатов проверки. Саму функцию дорабатываем в HTML-файле и проверяем в браузере.

## Ситуация

В учебной компании «ГородМаркет» есть форма заявки на доставку. Она показывает подтверждение даже тогда, когда имя клиента не введено. Менеджер попросил исправить это. Для проверки используйте вымышленные имена.

**План продукта** описывает, какую пользу получит пользователь и что команда собирается сделать в ближайшей версии. **Бэклог** — список предложенных работ. Из него выбирают, что войдёт в ближайшую версию. **Критерии приёмки** — проверяемые условия, по которым решают, готова ли функция.

## 1. Зафиксируйте первую версию в Битрикс24

1. Откройте свой Битрикс24 в браузере.
2. В левом меню нажмите **«Задачи»** или **«Задачи и проекты»**.
3. Над списком задач нажмите **«Создать»**. Если открылась короткая форма, нажмите **«Полная форма»** внизу справа.

![Кнопка «Полная форма» в окне создания задачи](images/product-task-form.jpg)

4. Введите название **«Урок 18 — первая версия проверки заявки»**.
5. В поле **«Исполнитель»** выберите себя. Если ваше имя уже указано, оставьте его.
6. В поле **«Крайний срок»** укажите срок сдачи, который назвал преподаватель. Если срок не задан, выберите завтра, 18:00.
7. В описание вставьте следующий план. Прочитайте его и своими словами дополните строку «Пользователь».

   - **Пользователь:** менеджер доставки.
   - **Проблема:** форма подтверждает заявку с пустым именем.
   - **Первая версия:** отклонять пустое имя и имя из одних пробелов. При заполненном имени показывать подтверждение.
   - **Следующая версия:** добавить поле «Время доставки» и обсудить, должно ли оно быть обязательным.
   - **Результат работы:** исправленный HTML-файл и запись о трёх проверках.

8. Нажмите **«Создать»**. Найдите задачу в списке и откройте её.

**Проверьте себя.** В описании видно, что войдёт в первую версию и что отложено. Бэкенд, база данных, отправка заявок и поле времени доставки выходят за рамки упражнения.

[Официальная инструкция по форме задачи](https://helpdesk.bitrix24.ru/open/27359038/)

## 2. Откройте прототип и воспроизведите ошибку

1. Откройте [учебный HTML-файл](examples/mayak-request.html). На GitHub нажмите **«Download raw file»** (значок загрузки над кодом). Если значка нет, щёлкните правой кнопкой по [ссылке на исходный файл](https://raw.githubusercontent.com/PKO-LP/Bitrix24_manuals/main/examples/mayak-request.html) и выберите «Сохранить ссылку как».
2. В папке «Загрузки» найдите **mayak-request.html**. Проверьте, что имя заканчивается на **.html**.
3. Дважды щёлкните файл. В браузере появится страница **«Заявка на доставку»**.
4. Оставьте поле имени пустым и нажмите **«Проверить заявку»**.
5. Запишите увиденное. Исходная форма показывает **«Заявка проверена:»** даже без имени.
6. Откройте задачу в Битрикс24 и добавьте комментарий **«Ошибка воспроизведена: пустое имя приводит к подтверждению»**.

**Проверьте себя.** Вы можете повторить ошибку по двум действиям: оставить поле пустым и нажать кнопку проверки.

## 3. Внесите изменение в код

1. Откройте **mayak-request.html** в VS Code или другом редакторе обычного текста. В VS Code можно нажать **«Файл → Открыть файл»** и выбрать скачанный файл.
2. Через поиск в редакторе найдите строку **// Вставьте проверку имени здесь.**
3. Замените только эту строку следующим фрагментом.

   ```js
   if (!name) {
     result.textContent = 'Введите имя клиента.';
     return;
   }
   ```

4. Сохраните файл через **Ctrl+S** в Windows или **Cmd+S** на Mac.
5. Вернитесь во вкладку с локальной формой и обновите страницу. Если на экране открыт GitHub, снова откройте скачанный файл с компьютера.

**Как работает изменение.** Строка `customer.value.trim()` убирает пробелы по краям. Если после этого имя пустое, форма показывает сообщение об ошибке. Команда `return` завершает проверку до строки с подтверждением.

## 4. Выполните приёмку

Проверяйте все три случая в одной открытой форме. Перед каждой проверкой очищайте поле.

1. Введите **«Мария Соколова»**. Нажмите кнопку проверки. Ожидаемый текст — **«Заявка проверена: Мария Соколова»**.
2. Очистите поле. Нажмите кнопку проверки. Ожидаемый текст — **«Введите имя клиента.»**
3. Введите несколько пробелов. Нажмите кнопку проверки. Ожидаемый текст — **«Введите имя клиента.»**
4. Если хотя бы один результат отличается, проверьте, что файл сохранён, вкладка обновлена, а новый фрагмент стоит между строкой с `trim()` и строкой с подтверждением. Повторите все три проверки.

**Проверьте себя.** После успешного случая форма заменяет старое подтверждение сообщением об ошибке, если следующее имя пустое.

## 5. Зафиксируйте результат и следующий шаг

1. Вернитесь в свою задачу в Битрикс24.
2. Добавьте комментарий с результатами. По каждому случаю укажите, что ввели, какой текст появился и совпал ли он с ожидаемым.
3. Сдайте исправленный **mayak-request.html** способом, который указал преподаватель. Если работа сдаётся показом, откройте файл в браузере и выполните три проверки при преподавателе.
4. Вернитесь к строке «Следующая версия» в плане. Запишите в комментарии один вопрос к заказчику про время доставки, например **«Можно ли оставить заявку, если время доставки ещё неизвестно?»** Этот вопрос поможет уточнить следующее требование до написания кода.
5. Когда проверки пройдены, нажмите **«Завершить»** в задаче. Если одна из проверок ещё не проходит, укажите это в комментарии и оставьте задачу открытой.

**Что показать преподавателю** — задачу с планом первой и следующей версий, исправленный файл и результаты трёх проверок.
