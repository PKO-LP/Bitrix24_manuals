# Битрикс24 с нуля

Самоучитель для занятий в браузере. Откройте уроки по порядку.

1. [Регистрация и первая сделка](01-first-steps.md) — войдите в Битрикс24, добавьте учебного клиента, создайте сделку и переместите её на следующую стадию.
2. [Новое поле и автоматическая задача](02-automation.md) — настройте карточку, добавьте робота и проверьте его на учебной сделке.

3. [История изменений в CRM](03-crm-history.md) — найдите событие по учебной сделке и сравните историю с таймлайном карточки.

4. [Контакт, компания и записи в карточке](04-crm-records.md) — создайте связанные записи с нуля, добавьте комментарий и запланируйте дело.

5. [Поиск и фильтры в CRM](05-crm-search.md) — найдите сделку, отберите записи по стадии и сохраните фильтр.

6. [Задача по сделке](06-crm-task.md) — поставьте задачу, запишите результат и завершите её.

[Официальные материалы по всем урокам](materials.md)

Для первого урока достаточно бесплатного тарифа. Для робота во втором уроке нужен доступ к автоматизации CRM, например активное демо. [Условия демо](https://helpdesk.bitrix24.ru/open/22476482/)

В уроках есть официальные скриншоты Битрикс24. В первом уроке также показан обезличенный фрагмент бокового меню.
