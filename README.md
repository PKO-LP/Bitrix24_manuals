# Битрикс24 с нуля

Самоучитель для занятий в браузере. Откройте уроки по порядку.

1. [Регистрация и первая сделка](01-first-steps.md) — войдите в Битрикс24, добавьте учебного клиента, создайте сделку и переместите её на следующую стадию.
2. [Новое поле и автоматическая задача](02-automation.md) — настройте карточку, добавьте робота и проверьте его на учебной сделке.

Для первого урока достаточно бесплатного тарифа. Для робота во втором уроке нужен доступ к автоматизации CRM, например активное демо. [Условия демо](https://helpdesk.bitrix24.ru/open/22476482/)

На иллюстрациях используются фрагмент меню и учебные схемы.
